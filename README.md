## 📊 AI Detection Forensics (Why Other Detectors Fail)

Standard detectors frequently misidentify normal formal human writing as AI due to:
1. **Flawed Baseline Assumptions**: Starting scores that default to uncertain/AI unless text contains slang.
2. **Artificial Penalty on Grammatical Precision**: Punishing complete sentences (12–22 words) as "too uniform".
3. **Broken Perplexity Formats**: Using uncalibrated formulas that go negative on normal text containing frequent functional words ("the", "and").

**How Sanvox AI Solves This:**
- **Calibrated Shannon Entropy**: Measures genuine information surprisal across bigrams and unigrams without collapsing into negative scores.
- **Burstiness Coefficient of Variation (CV)**: Accurately distinguishes human sentence-length diversity (CV 0.35–0.90) from machine uniformity (CV 0.10–0.25).
- **Graceful Self-Contained Execution**: Runs locally in milliseconds with optional external benchmark verification.

## 💻 Quickstart & Installation

### Requirements
- Node.js >= 20.0.0
- npm / pnpm

### 1. Clone the repository
```bash
git clone https://github.com/shivankthakurr/sanvox-ai.git
cd sanvox-ai
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to start using Sanvox AI.
